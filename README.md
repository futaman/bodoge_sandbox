# bodoge_sandbox

[![Deploy to GitHub Pages](https://github.com/futaman/bodoge_sandbox/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/futaman/bodoge_sandbox/actions/workflows/deploy-pages.yml)

ルールを固定せず、カード・山札・コマ・チップ・サイコロ・ボードを自由に配置して試せる、汎用的なボードゲーム試遊用Webアプリです。

## デモ

**[GitHub Pagesでアプリを開く](https://futaman.github.io/bodoge_sandbox/)**

## 主な機能

### ゲーム設定

- プレイヤーの追加・削除・名前・カラー設定
- プレイヤーごとの手札、得点、役職の有効化
- スート、値、枚数を指定したカード生成
- 現在設定されているカードの一覧表示と削除
- 未配置カードから山札を作成
- プレイヤーとカード設定のJSON出力・読み込み
- 登録済みサンプル環境のプルダウン選択・読み込み

### 試遊画面

- カード、山札、サイコロ、チップ、コマの配置と移動
- 盤面の拡大・縮小、表示領域へのフィット
- 3倍の広さを持つホワイトボード型の盤面
- `Space`＋ドラッグ、またはホイール押し込み＋ドラッグによる盤面移動
- `Shift`＋クリックによるカードや盤上オブジェクトの複数選択
- `Shift`を押しながらドラッグした場合のグリッドスナップ
- 手札から盤面へのドラッグ＆ドロップ
- 手札から右ドラッグしてカードを裏向きで配置
- 盤上カードのダブルクリック／ボタンによる表裏反転
- 複数選択したカードの一括移動・反転・山札への返却
- プレイヤー間でのカード受け渡しと、選択カード同士の交換
- 山札のシャッフル、ドロー、全員への均等配布
- 山札から盤面へのカード配置
- 約0.5秒の演出を伴うサイコロロール
- サイコロのダブルクリックによるロール
- 色名に応じた視認性重視のカード配色
- 約0.2秒のカードフリップ演出
- カードを山札へ重ねて、一番上またはランダムな位置へ戻す操作
- プレイヤーカラーのコマ・チップを1人分または人数分まとめて追加

### ボード編集

- ゲーム用マスと装飾図形の作成・移動・複製・削除
- 番号付きマスの一括生成
- 線の描画・選択・移動・削除
- 線の端点を図形の四隅、辺の中央、中心へスナップ
- グリッド表示と位置スナップ
- 編集結果を試遊画面へ反映

### オンラインマルチプレイ

- 5文字のルームIDで作成・参加
- `/room/{ROOM_ID}` の招待URLから直接参加
- WebSocketによる盤面・カード・得点・ターンのリアルタイム同期
- 参加者のオンライン／離席表示と切断後の自動再接続
- ドラッグ操作の送信間引きと、同じオブジェクトを同時操作しないためのロック
- 山札順、シャッフル、ダイス結果をサーバー側で管理
- 他プレイヤーの手札内容を送信せず、枚数だけを共有
- ルーム状態をサーバーへ保存し、無人になってから約6時間保持
- 従来のローカルモードとの切り替え

## 基本操作

| 操作 | 結果 |
| --- | --- |
| オブジェクトをドラッグ | 盤面上を移動 |
| `Shift`＋クリック | 複数選択／選択解除 |
| `Shift`＋ドラッグ | グリッドにスナップして移動 |
| `Space`＋盤面をドラッグ | 表示範囲を移動 |
| ホイール押し込み＋ドラッグ | 表示範囲を移動 |
| `Ctrl`＋ホイール | 中央の盤面だけを20〜400%で拡大・縮小 |
| 手札のカードをドラッグ | 表向きで盤面へ配置 |
| 手札のカードを右ドラッグ | 裏向きで盤面へ配置 |
| 盤上カードをダブルクリック | 表裏を反転 |
| 山札をダブルクリック | 山札から1枚を盤面へ配置 |
| サイコロをダブルクリック | サイコロをロール |
| カードを山札へ重ねてドロップ | カードを山札の一番上へ戻す |
| `Ctrl`＋カードを山札へドロップ | カードを山札内のランダムな位置へ戻す |
| ボード編集時に`Alt`＋ドラッグ | スナップを一時的に無効化 |

## ローカルで起動する

### 必要なもの

- Node.js 22推奨
- npm

### セットアップ

```bash
git clone https://github.com/futaman/bodoge_sandbox.git
cd bodoge_sandbox
npm install
npm run dev
```

起動後、ターミナルに表示されたURLをブラウザで開いてください。通常は `http://localhost:5173` です。

オンラインモードも試す場合は、別のターミナルでWebSocketサーバーを起動します。

```bash
npm run build:server
npm run server
```

開発中にサーバーを自動再起動する場合は `npm run dev:server` を使えます。クライアントは既定で `ws://localhost:8787` へ接続します。

インターネットへ公開する場合、GitHub Pagesとは別にWebSocketサーバーをNode.js対応サービスへデプロイし、ビルド時の `VITE_MULTIPLAYER_URL` にその `wss://` URLを設定してください。設定例は [`.env.example`](.env.example) にあります。

同じLAN内のスマートフォンなどから確認する場合は、次のように起動します。

```bash
npm run dev -- --host 0.0.0.0
```

### 本番ビルド

```bash
npm run build
npm run preview
```

## GitHub Pagesへの公開

`main`ブランチへpushすると、GitHub Actionsが自動的に型チェック、ビルド、GitHub Pagesへのデプロイを行います。

ワークフローは [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) にあります。

## 現在の制約

- ローカルモードの試遊状態はブラウザを再読み込みするとリセットされます。オンラインルームはサーバー側に一時保存されます。
- JSONへ出力できるのは、現在のところプレイヤー設定とカード設定です。
- GitHub PagesだけではWebSocketサーバーを動かせないため、オンライン公開には別途サーバーのデプロイが必要です。
